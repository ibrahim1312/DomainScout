# DomainScout

An early-stage toolkit for domain investors and researchers.

## Current features

- Domain syntax validation and normalization
- Name length, extension, digit and hyphen analysis
- Optional DNS address lookup
- JSON output for multiple domains

## Usage

Requires Python 3.10+; no external dependencies.

```sh
python domainscout.py example.com example.org --resolve
python -m unittest discover
```

DNS results do not establish registration availability or market value.
